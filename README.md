# CALCX — Glass Lab Calculator

A modern, responsive calculator web application built using HTML, CSS, and JavaScript.

CALCX combines a clean calculator interface with scientific calculations, calculation history, keyboard support, and a simple calculation explanation feature.

## Features

- Basic arithmetic operations
- Scientific calculator mode
- Parentheses support
- Percentage calculations
- Square root
- Powers
- Factorial
- sin, cos, tan
- log and ln
- π and e constants
- DEG / RAD mode
- Calculation history
- Expression timeline
- Reuse previous calculations
- Calculation explanation
- Copy result
- Keyboard input
- Dark / Light theme
- Responsive mobile design
- Local storage for calculation history

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Handling
- LocalStorage
- Responsive Web Design
